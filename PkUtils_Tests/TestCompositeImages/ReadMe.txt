TestCompositeImages demonstrates using TPL Dataflow in a Windows Forms
application to build and execute a pipeline that processes input images and
creates composite images. It includes cancellation support.

The example is based on the MSDN article "Using Dataflow in a Windows Forms
Application":
https://msdn.microsoft.com/en-us/library/hh228605(v=vs.110).aspx

See CustomBlocks/ImageProcessingPipe.cs and UI/MainForm.cs.
