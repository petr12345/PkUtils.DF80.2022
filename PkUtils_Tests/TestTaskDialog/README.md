# Modern TaskDialogWrapper demonstration

This WinForms demo exercises `PK.PkUtils.UI.Dialogs.TaskDialogs.TaskDialogWrapper`:

- Information and Question dialogs
- Auto-closing notification (5 seconds)
- Auto-closing confirmation (10 seconds, Continue by default)

Open either `.sln` file in this directory or the matching `PkUtils_Tests.DF*.sln` at the parent level.

The old `VistaTaskDialogManager` demonstration is preserved separately in `../TestVistaTaskDialog/`.

Build validation requires the .NET 8 / 10 Windows SDK and Windows Forms environment.
